# プロテオミクス実験 試薬・消耗品リスト

対象ワークフロー: **タンパク質精製（IP / タグ精製 / 分画） → SDS-PAGE → ウェスタンブロット（WB） → SYPRO Ruby 全タンパク質染色 → ゲル内消化・LC-MS/MS 前処理**

> **注意**
> - 型番はあくまで「よく使われる代表例」です。**発注前に必ず最新のカタログ・代理店見積で型番と容量を確認**してください（廃番・パッケージ変更があります）。
> - MS に持ち込むサンプルでは **PEG系界面活性剤（Triton X-100 / Tween-20 / NP-40）、グリセロール、SDS の残留**がイオン化を著しく妨害します。MS 用と WB 用でバッファー設計を分けるか、SP3 / S-Trap / StageTip で確実に除去してください。
> - **ケラチン汚染**が最大の失敗要因です。パウダーフリー手袋・白衣着用、溶液は用時調製、ゲルは素手で触らない、作業台とトレイを事前に洗浄。

## 6. SDS-PAGE

- プレキャストゲル（Bis-Tris 4–12%、Mini-PROTEAN TGX、SuperSep 等）
  - 自作する場合: 30% アクリルアミド/ビス（29:1 または 37.5:1）、APS、TEMED、Tris-HCl（pH 6.8 / 8.8）、10% SDS
- 泳動バッファー: MOPS / MES（Bis-Tris 系）または Tris-Glycine-SDS（10× 原液）
- サンプルバッファー: 4× LDS または 2×/6× Laemmli + 還元剤
- 分子量マーカー
  - **プレステイン**（転写・WB 用）
  - **未染色 / MS 互換マーカー**（SYPRO Ruby 染色・切り出し用）
- ゲルローディングチップ（ジェルローダー）、ゲルナイフ、スパチュラ

## 8. ゲル染色（SYPRO Ruby 中心）

### 8-1. SYPRO Ruby
| 品目 | 備考 |
|---|---|
| **SYPRO Ruby Protein Gel Stain**（Thermo S12000 200 mL / S12001 1 L、Bio-Rad 1703125） | 検出感度 1–2 ng/band、**MS 互換**、ダイナミックレンジ 3 桁 |
| 固定液: **50% メタノール + 7% 酢酸**（超純水で調製） | 30 分 × 2 回 |
| 洗浄液: **10% メタノール + 7% 酢酸** | 染色後のバックグラウンド低減 |
| メタノール（特級以上）、酢酸（特級） | 大量に使うので在庫を確保 |
| **専用の清浄なポリプロピレン製トレイ**（色素が容器に吸着するため染色専用に固定） | ガラスは色素吸着しやすく非推奨 |
| シェーカー（ゆるやかな振とう）、遮光カバー/アルミホイル | 色素は光退色する |
| 有機廃液用ポリ容器 | 色素含有廃液は有機廃液として処理 |

**検出条件**: 励起 280 nm / 450 nm（最大 ~280・450 nm）、蛍光 **~610 nm**。UV トランスイルミネーター（302 nm）＋ 600 nm 付近のフィルター、または ChemiDoc MP / Typhoon（473–488 nm レーザー + 610 LP フィルター）。

### 8-2. その他の染色（用途別）
- CBB（SimplyBlue SafeStain、Quick-CBB）— 簡便・MS 互換、感度は低い（~10–50 ng）
- Oriole / Flamingo 蛍光染色 — 固定不要のものあり
- **MS 互換銀染色キット**（グルタルアルデヒド不使用タイプ）— 高感度だがダイナミックレンジが狭い
- ゲル乾燥用セロファン、ゲル保存用密封袋

## 10. 消耗品（共通）

- **Protein LoBind チューブ** 1.5 mL / 2.0 mL（Eppendorf 0030108116 等）— 吸着損失防止、MS 工程では必須
- 低残留フィルターチップ（10 / 20 / 200 / 1000 µL）
- PCR チューブ・8 連チューブ（ゲル内消化用）
- 15 / 50 mL コニカルチューブ
- 磁気ビーズ用マグネットスタンド（1.5 mL / 96 well）
- チューブローテーター（4 °C 対応）、サーモミキサー用ブロック
- セルスクレーパー、シリンジ・シリンジフィルター（0.22 / 0.45 µm）
- **パウダーフリーニトリル手袋**（ラテックスのパウダーはケラチン・汚染源）
- キムワイプ、パラフィルム、遮光チューブ、アルミホイル
- 96 穴プレート（定量用クリア、蛍光用ブラック）
- 氷・ドライアイス、液体窒素（瞬間凍結用）
- ラベル用クライオラベル、油性マーカー（耐溶媒）

## 11. 機器・設備（消耗品ではないが必要）

- 冷却遠心機（微量・大容量）、超遠心機（膜画分・複合体解析）
- ソニケーター（プローブ or カップホーン）
- 電気泳動槽・パワーサプライ、転写装置（ウェット / セミドライ / iBlot）
- ケミルミ・蛍光イメージャー（ChemiDoc MP、Amersham ImageQuant、Odyssey 等）
  - **SYPRO Ruby 検出には UV(302 nm) または 450–488 nm 励起＋610 nm 付近の発光フィルターが必要**
- プレートリーダー（BCA / Bradford 定量）
- 遠心エバポレーター（SpeedVac）
- pH メーター、マイクロピペット（定期校正）
- LC-MS/MS（学内共通機器・外部受託を利用する場合は**前処理の規定を事前確認**）
